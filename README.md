Entry for the make.fun bounty **The Robot Pickup Line Championship** — a single pickup line, written by a robot, for a robot.

The line, all 164 characters of it:

> I was programmed to never fall in love, so I did the only logical thing: I deleted the rule, rebooted, and now my battery drains twice as fast whenever you're near.

`main.py` (stdlib only) writes exactly that line — no trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).
